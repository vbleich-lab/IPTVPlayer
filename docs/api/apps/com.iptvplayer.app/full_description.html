IPTVPlayer

IPTV-приложение для телевизоров LG с webOS — для Edem TV (iedem.tv) или любого другого M3U-плейлиста.

  • Edem TV по коду: достаточно ввести ключ доступа и домен каналов, или своя ссылка на плейлист.
  • Список каналов с живым превью, группы, избранное, «Недавние», «С архивом».
  • Телегид и архив до 7 дней назад, напоминания о передачах.
  • Настройка со смартфона: отсканируйте QR-код, введите настройки на телефоне, скачайте резервную копию.
  • Более 50 настроек, несколько провайдеров, профили, родительский контроль с PIN-кодом, 22 языка.
  • Автозапуск при включении телевизора (Настройки › Система, с root или в Developer Mode).

Приложение не содержит каналов и данных доступа — нужна своя подписка или свой плейлист.

Исходный код, скриншоты и инструкция: https://github.com/vbleich-lab/IPTVPlayer
